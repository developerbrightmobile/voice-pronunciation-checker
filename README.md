# voice-pronunciation

Проверка произношения английского языка для Hermes Agent.

Скрипт принимает аудио (голосовое из Telegram, файл или запись с микрофона),
распознаёт речь через Groq Whisper, сравнивает с ожидаемым текстом и просит LLM
дать IPA-транскрипцию, оценку по словам и советы на русском.

## Требования

- Python 3.10+ (используется только стандартная библиотека)
- `ffmpeg` (конвертация аудио и запись с микрофона)
- `GROQ_API_KEY` — читается из `/root/.hermes/.env` или переменной окружения
- Для записи с микрофона: `pulseaudio` или `alsa` (`libasound2`)

Никаких `pip install` не требуется — HTTP реализован через `urllib`.

## Использование

```bash
# Проверить существующий файл против ожидаемого текста
python3 pronounce.py voice.ogg --reference "Hello, my name is Kirill"

# Без ожидаемого текста (только уверенность распознавания + IPA от LLM)
python3 pronounce.py voice.ogg

# Записать 5 секунд с микрофона
python3 pronounce.py --record 5 --reference "Good morning"

# Без LLM (офлайн-эвристика: diff + уверенность Whisper)
python3 pronounce.py voice.ogg -r "Hello" --no-llm

# Машиночитаемый результат
python3 pronounce.py voice.ogg -r "Hello" --json --out result.json
```

### Основные опции

| Флаг | Описание |
|------|----------|
| `audio` | путь к аудиофайлу (позиционный) |
| `-r, --reference` | ожидаемый текст |
| `-R, --record SECONDS` | запись с микрофона |
| `--device` | устройство записи (по умолчанию `default`) |
| `-l, --language` | язык (по умолчанию `en`) |
| `--stt-model` | модель Whisper (по умолчанию `whisper-large-v3-turbo`) |
| `--llm-model` | модель анализа (по умолчанию `openai/gpt-oss-120b`) |
| `--no-llm` | не вызывать LLM |
| `--json` | печатать только JSON |
| `--out FILE` | сохранить JSON в файл |
| `--api-key` | ключ Groq (иначе env / `.env`) |

## Как это работает

1. **Аудио** приводится к 16 кГц моно WAV через ffmpeg.
2. **Whisper** (`whisper-large-v3-turbo`, Groq) возвращает `verbose_json` с
   пословными таймстемпами и `avg_logprob` по сегментам.
3. **Сравнение** (если задан `--reference`): `difflib` находит пропущенные,
   лишние и неверно распознанные слова → точность в процентах.
4. **Уверенность**: сегменты с низким `avg_logprob` (< `-0.6`) помечаются как
   подозрительные.
5. **LLM** получает транскрипт, diff, confidence и возвращает JSON со оценкой
   0–100, IPA для каждого слова, per-word статусами и советами на русском.

## Ограничения (важно)

Whisper **не измеряет произношение напрямую** — он нормализует речь к ближайшим
известным словам. Поэтому сигналов ровно два:

- расхождение распознанного текста с ожидаемым (`--reference`);
- низкая уверенность модели (`avg_logprob`).

Это хорошая эвристика, но не фонетический анализатор уровня GOP/forced
alignment. Совет по конкретному звуку — рекомендация LLM, а не измерение.
